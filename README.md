# Healthcare-Content-Generator-
Healthcare Content Generator is a Generative AI powered application that automatically creates accurate, structured, and easy-to-understand healthcare content using Large Language Models (LLMs) and Vector Databases.  The system allows users to input a medical topic, symptom, or disease.

## Local development environment

I created a Python virtual environment named `Healthbot` inside this project. To activate it on Windows PowerShell run:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
.\Healthbot\Scripts\Activate.ps1
```

Once activated, install dependencies with:

```powershell
python -m pip install -r requirements.txt
```

To deactivate:

```powershell
deactivate
```
